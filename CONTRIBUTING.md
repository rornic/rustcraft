# Contributing

Thanks for your interest in Ochre. It's a personal project with a direction I want to steer, so please read this before opening a pull request.

## Discuss first

**Open an issue before starting any non-trivial change.** Describe what you want to do and why, and wait for agreement before writing code.

Pull requests that add features, restructure code, or touch more than a handful of lines without a prior discussion will likely be closed, however well made. This isn't a judgement on the work; it just may not fit where the project is going.

## What's welcome without discussion

- Small bug fixes with a clear description of the bug.
- Typo and documentation fixes.

If you're unsure whether your change counts as small, open an issue and ask.

## Pull requests

- Link the issue where the change was agreed.
- Keep each PR focused on one change.
- Make sure `cargo build --workspace --all-targets` and `cargo clippy --workspace --all-targets` pass.
